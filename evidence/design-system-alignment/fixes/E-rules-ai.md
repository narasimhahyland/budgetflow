## Shared requests (for the owner of `libs/web/ui` and the shell)

1. **`data-table.scss`, stacked mode** (blocks E9 at 412 everywhere). In `@media (width < 600px)`, add: `.bf-table--stack { display: block; }`, `.bf-table--stack tbody td, .bf-table--stack tbody th { flex-wrap: wrap; white-space: normal; }`, `.bf-table--stack tbody td[data-label]::before { flex: 0 0 auto; }`, `.bf-table--stack tbody tr > :first-child:not([data-label]) { display: block; text-align: start; font-weight: 500; }`. Without these, the table keeps `display: table` and grows to its widest flex cell (016b: 494px in a 378px card). Proven by injection in `fix-E/stackfix-016b.png`.
2. **Shell header at 412px (fork A).** `.bf-header__actions` / `sat-app-header-trailing-container` overflow `main#main-content` by 19–72px when the mobile title is long (071a, 077, 061f, 016b). Truncate the title with ellipsis or let the actions shrink. This is the only blocking item left in my screens.
3. **`formatMoney`:** use a non-breaking space between the currency code and the amount, so "USD / 1,200.00" never breaks across lines in sentences (068 condition text).
4. **API (not web):**
   - Anomaly evidence and policy evidence as `Money` instead of `toFixed` strings (017c).
   - Allocation suggestion copy: remove "(22a)" and use `formatMoney` for rounding (022d).
   - A user-readable `ask_chat` feature state, so 061f can show "turned off" on load.
   - Split actual vs committed in `BudgetOutlook` for a section 10 bar (016b).
   - `pendingOthers` on `BudgetImpact` (parent's note).
