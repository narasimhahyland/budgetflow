## Shared requests

1. **`data-table.scss` (stacked mode):** let cell content wrap: `.bf-table--stack tbody :is(td, th) > * { min-width: 0; overflow-wrap: anywhere; }`. Long handles and e-mails otherwise widen the card. 061e works around it locally.
2. **`data-table.scss` (pinned actions):** consider moving my tablet "pinned last column" rule from `integrations.scss` into a shared `bf-table--pin-actions` modifier. Note: Material creates the `tbody`/`thead` itself, so component-scoped selectors must not go through them.
3. **`capture.mjs`:** three problems.
   - (a) The page-scroller test treats a tall `.bf-table-scroll` as the page, because `overflow-x: auto` computes `overflow-y: auto`. It then reports an intended table scroll as page overflow. Require `scrollHeight > clientHeight`, or skip `.bf-table-scroll`.
   - (b) `growToContent` also measures the off-canvas mobile navigation drawer, so mobile captures get a long blank tail. Apply the same "on screen and at least half the viewport wide" filter.
   - (c) `--only 092` does not match `092a`–`092d`.
4. **Role labels:** move `ROLE_LABELS` (`libs/web/shell/src/lib/nav.ts`) to `libs/web/data-access`. `mobile/labels.ts` holds a copy.
5. **Shell app header (fork A):** truncate long route titles. At 412 px the trailing FY/avatar group overflows.
6. **Contract:** add bucket amounts to `WidgetTeamBudget`, so the embed can use `bf-budget-bar`.
7. **Routes:** a mobile app frame layout route for `/m/*` (`apps/web` routes).
