## Shared requests (for the parent)

1. **capture.mjs false positive.** A tall `.bf-table-scroll` (overflow-x auto, so overflow-y computes to auto) counts as a page-sized scroller, so intended scrolling inside a table is reported as page overflow (090 tablet, 197px). Exclude elements whose `overflow-x` is auto/scroll from the page-scroller check, or require `overflow-y` to be explicitly set.
2. **Heading weight 600 adds a font-swap layout shift.** `.bf-page__title` at 600 renders wider in the fallback font while Figtree loads, so a title-plus-tag row wraps and then unwraps (065 tablet, CLS 0.36; fixed locally by stacking). Other pages with a title and tag near the wrap width can hit this. Preload the Figtree face, or reserve the title row.
3. **`bf-budget-impact` "this request" heuristic.** `pending >= thisRequest` treats another request's pending amount as this one's (065: pending USD 216 is REQ-00002, so this request's USD 215.57 hatched segment is hidden). Needs `pendingOthers` (or an `includesThisRequest` flag) from the API.
4. **Empty `bf-load-state` inside a flex column adds a phantom gap.** Every page that keeps `<bf-load-state>` mounted after load gets one extra flex gap. Fixed locally for 056/057/058/118 by rendering it only on error. Consider `:host { display: contents }` or rendering nothing when idle in the shared component.
5. **120 computes used and open amounts in the component** (frontend-angular: the API returns balances). Needs API fields.

Proposed `screens.json` entries: `tmp/audit/fixes/D-screens.json` (057 filled and blocked, 059 escalated tab, 061 missing-amount state, 062 delegations screen, 090 mask on the time text only).
