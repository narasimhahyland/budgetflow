## Fixes found while proving the flows

- Event organizers could not open Request funds or Upload receipt: the tenant-level check for home-unit actions (request, contribution, event) ignored the home location (`libs/domain` policy).
- Giving budgets on an event can be searched (the candidate list is capped); requestable budgets keep the newest 100 the viewer may use.
- A pending approval step reads "Pending" (the route is also shown to requesters).
- `scripts/gate.sh` reseeds before visual when functional modes ran, matching CI's separate visual job.
- The visual capture script ignores the browser's console line for a request a state explicitly allows to fail; no global 4xx ignore.
