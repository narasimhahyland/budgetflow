# Phase 4 functional check

Local Docker Compose stack on the worktree ports (`scripts/stack.sh up && reset`, deterministic seed), real Keycloak tokens per role, real Postgres with RLS. API scenarios: `apps/api-e2e/src/budgets` (Phase 4 scenarios in `controls`, `transfers-requests`, `per-head-grid` and `planning`, plus the over-allocation, concurrency and idempotency scenarios from Phase 1 that now run on the USD seed; 42 budget scenarios in total). Journeys: `apps/web-e2e/src/budgets/budgets.spec.ts` (10 on desktop; the 6 read-only ones also run on tablet and mobile). Both suites ran inside the full gate (`../gate-summary.txt`) and again without a reset for these listings: `api-scenarios.txt` (201 passed, whole API suite), `journeys.txt` (173 passed, 26 skipped: mutating journeys run on desktop only). Scenario data is created through the API, so the suites repeat on a used database.
