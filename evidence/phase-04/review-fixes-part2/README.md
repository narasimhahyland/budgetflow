# Phase 4 review fixes, part 2 (branch `fix/p4-followup-part2`)

Completes the remaining Phase 4 review and decision-log items after Wave 2 (Phases 4, 5, 6 and Wave 2 core acceptance) merged to `main` at `e422d7f`:

1. **Approved plan versions are immutable (`0007_p4_plan_baseline`).** Database trigger `plan_version_lines_immutable` (`app_plan_version_line_guard`) rejects `INSERT`, `DELETE`, and any `UPDATE` other than linking `budget_id` from `NULL` on non-draft plan versions. `POST /api/budgets` for a root budget links an existing unlinked plan line (matched by code and reporting amount) and otherwise returns `409 PLAN_REVISION_REQUIRED`.
2. **Two-person sign-off for new money (`new_money_finance_approved_*`, `new_money_ceo_approved_*`).** When a plan revision increases the year's controlling plan total (or adds a new root line), `POST /api/plan-versions/:id/approve` requires both a Finance Admin and the CEO (two distinct people, neither the drafter: `409 SELF_APPROVAL`, `409 PLAN_SIGNOFF_REQUIRED`). Added second Finance Admin seed user `finance-admin-2` (`finance.admin2@example.test`) in `libs/seed` and `infra/keycloak/budgetflow-realm.json`. Scenario root factories in `apps/api-e2e` and `apps/web-e2e` create roots through additive plan revisions whose linked lines join the year's tie-out.
3. **Contingency reserve as a separate root (`EX-RESERVE`).** `Central Contingency Reserve` (`71000000-0000-4000-8000-000000000005`) is seeded as its own root under Hyland with its own plan line (`USD 3,000.00`). Approved contingency releases (`POST /api/budgets/:id/releases` + `POST /api/budget-requests/:id/decision`) perform the cross-root move (`allowCrossRoot` in `postHierarchyMove`) while keeping the hierarchy and plan tie-out balanced.
4. **Monthly per-head rate proration.** `perHeadAmount` multiplies `rateMinor × eligibleHeadcount (prorated) × monthsLeftInFiscalYear`, and `perHeadTrueUp` posts `rateMinor × headcountChange × monthsLeft`. Updated the contract description and UI label to `"Rate per eligible employee per month (USD)"`.
5. **Verified `return_unfit` on budget reduction.** Already completed in Part 1 (`4ed0314`) and consumed by Phase 5 (`BudgetControlConsumer`, proven in `apps/api-e2e/src/requests/controls.spec.ts`).
