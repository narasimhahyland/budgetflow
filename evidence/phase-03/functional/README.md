API scenarios: `apps/api-e2e/src/org`, `apps/api-e2e/src/finance` (40 scenarios, `api-scenarios-phase3.txt`). Journeys: `apps/web-e2e/src/org`, `apps/web-e2e/src/finance-admin` (23 per viewport on desktop; read-only ones also on tablet and mobile, `journeys-phase3.txt`). Both suites also ran inside the full gate (`../gate-summary.txt`) and repeat without a reset (scenario data is dated in future years or uniquely coded).
