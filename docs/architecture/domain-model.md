# Domain model

All Phase 1 domain tables exist (73 tables, `libs/api/db/src/schema/*.ts`, migration `0000_init_schema`). Every tenant-owned table has `tenant_id`, a composite index starting with it, and RLS enabled and forced. Money columns are `bigint` minor units with `char(3)` currency codes; timestamps are `timestamptz` (UTC); dates are `date`. Rules live in `libs/domain` (framework-free); the "Writes from" column says which phase first writes the table through an API command.

## Domain library map (`libs/domain/src/lib`)

| Module           | Exports                                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `ledger/`        | Accounts and `NORMAL_SIGN`, `buildJournal` (balance check), `reverseJournal`, balances and `availableOf`, `checkAllocation`, `checkSpend`, `checkNotOverdrawn`, `thresholdsCrossed`, posting builders, rebuild comparisons |

| `lifecycles.ts`  | Commitment, event, request, contribution, forecast and recharge machines                                                                                                                                                   |
| `authority/`     | `resolveLimit`, `checkAuthority` (DoA, exact limit passes), `delegatedLimit`, `checkApprovalHygiene`                                                                                                                       |
| `cofunding/`     | `decideContribution`, `resolveIntercompany`, `fundingCap`, `checkFundingCap`, `surplusReturns`, `canCloseEvent`, `checkMatchOnce`, `duplicateKey`                                                                          |
| `authorization/` | `ROLE_IDS`, `ACTIONS`, `ROLE_GRANTS`, `can`                                                                                                                                                                                |
| `audit/`         | `canonicalJson`, `auditHash`, `verifyAuditChain`, `diffChanges`                                                                                                                                                            |

Every function returns `{ ok: true, value }` or `{ ok: false, error: { code, message, params } }` for business failures; error codes are listed in `DOMAIN_ERROR_CODES` and mirrored in `libs/contracts` `PROBLEM_CODES`.
